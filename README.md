# Email Sender Bot

This is a Python project that sends automated emails using Gmail SMTP.

## Features
- Send emails using Python
- Supports multiple recipients
- Uses Gmail App Password
- Command-line arguments support
- Optional attachment support

## How to Run

1. Install Python
2. Run the script using:

python email_sender.py --sender your_email@gmail.com --password your_app_password --to receiver@gmail.com --subject "Test" --body "Hello"

## Note
Use Gmail App Password instead of your normal password.
